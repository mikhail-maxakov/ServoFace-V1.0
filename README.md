 ##  Возможности

| Функция | Описание |
|---------|----------|
|  **Независимая горизонталь** | Левый и правый глаз двигаются влево-вправо асинхронно (±30°) |
|  **Общая вертикаль** | Оба глаза одновременно поднимаются и опускаются (±30°) |
|  **Моргание** | Веки синхронно закрываются каждые 4 секунды |
|  **Автономность** | Полностью циклический алгоритм — не требует датчиков или команд |
|  **Plug & Play** | Залейте код — и устройство сразу начнёт работать |
